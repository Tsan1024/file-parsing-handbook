# 图片解析指南

[English](README_EN.md) | 中文

## 概述

图片文件（JPG, PNG, TIFF 等）的文字识别和扫描件处理。

## 常用工具

| 工具 | 语言 | 说明 |
|------|------|------|
| Tesseract | C++/Python | 开源 OCR 引擎 |
| EasyOCR | Python | 深度学习 OCR |
| PaddleOCR | Python | 百度 OCR 框架 |
| ABBYY | 商业 | 专业 OCR。 |
