# Image Parsing Guide

## Overview

Image files (JPG, PNG, TIFF, etc.) for text recognition and scanned document processing.

## Common Tools

| Tool | Language | Description |
|------|----------|-------------|
| Tesseract | C++/Python | Open-source OCR engine |
| EasyOCR | Python | Deep learning OCR |
| PaddleOCR | Python | Baidu OCR framework |
| ABBYY | Commercial | Professional OCR |
