# Excel Parsing Guide

## Overview

Excel documents (.xlsx) are the standard format for spreadsheets. Legacy .xls format requires dedicated libraries such as xlrd.

## Common Tools

| Tool | Language | Description |
|------|----------|-------------|
| openpyxl | Python | Excel reading and writing |
| pandas | Python | Data analysis and processing |
| Apache POI | Java | Office document processing |
| SheetJS | JavaScript | Browser-side Excel processing |
.
