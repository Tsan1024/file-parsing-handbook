# Markdown Parsing Guide

## Common Tools

| Tool | Language | Description |
|------|----------|-------------|
| python-markdown | Python | Markdown parsing and rendering |
| markdown-it | JavaScript | High-performance Markdown parsing |
| remark | JavaScript | Markdown AST processing |
